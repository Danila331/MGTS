# MGTS

Новый проект. Исходные материалы по интерфейсу перенесены из `Danila331/mts-ai` (ветка `dev`) в `web/DESIGN.md` и `web/.impeccable/`. Они описывают прежний продукт и служат референсом, а не требованиями к MGTS.

Работа ведётся в ветках от `main`. Изменения в `main` автоматически выкатываются на Vercel и Railway. Дополнительные CI-проверки не настроены.

Пока в репозитории только стартовая страница (`web/public`) и минимальная служба состояния (`backend`); продуктовая функциональность ещё не реализована.
